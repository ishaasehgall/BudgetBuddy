
# Release Notes

## v1.0 - 2026-11-12

### Added
- Added a terminal menu for managing transactions and checking account balances.
- Added the ability to save and view transactions.
- Added category filtering to help users find specific transactions.
- Added a category breakdown showing the number of transactions in each category.
- Added a spending summary showing total spending and average transaction amounts.
- Added an account summary showing the number of recorded transactions.

### Fixed
- Fixed category counting so transactions are grouped under the correct category.
- Fixed the most recent transaction lookup to return the last item in the transaction history.

### Known Limitations
- The category totals report is not yet complete.
- New transactions entered through the menu use the default category.
- Some features may not handle an empty transaction history.
